ctrl + o to load a file
ctrl + s to save to file
backspace/delete to delete the nearest node to your cursor
insert or i to insert a node as a child of the nearest node to your cursor
hold click to drag the nearest node around
hold right click to pan
scroll wheel to zoom
double click to rename the nearest node

how to run:
get Love2D, then run the program like this:
love .
(assuming you are in the project directory)
